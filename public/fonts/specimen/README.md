# Specimen fonts

Tiny subsets (only the letters shown) of open-source fonts, used for the typeface specimens in the
Outgrow and Jain Connect case studies. All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org); the copyright notices are kept inside each file.

- Noto Sans, Noto Sans Tamil, Noto Sans Malayalam, Noto Sans Kannada — The Noto Project Authors
- Mukta (Devanagari) — Ek Type
- Poppins — The Poppins Project Authors (Indian Type Foundry)

Source files: @fontsource packages on npm. Re-create with fonttools `pyftsubset --text="…" --layout-features=* --name-IDs=* --flavor=woff2`.
